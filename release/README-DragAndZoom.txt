Drag-and-zoom
=============

Install vatSys.DragAndZoom.dll in the active vatSys Profile's Plugins directory.

Usage:
- Hold the right mouse button and drag to pan the ASD map.
- Release the right mouse button to keep the final map position.
- Use the mouse wheel to zoom.

This is a separate plugin from vatSys.PersistentPan.dll. Do not install both
unless you intentionally want both input handlers loaded.

The DLL must be built against the same vatSys.exe version that loads it.
